# Upgrade kits

<span class="status-chip pending">Step-by-step procedures pending verification</span>

Upgrade instructions must match the robot revision and the exact kit. This page names the planned guides and the checks each one must contain.

## 3 kg upgrade guide

Will cover kit inventory, compatible 1 kg base models, structure and weight changes, wiring or power changes, firmware configuration, balance checks, and a controlled first test.

## RC conversion guide

Will cover approved transmitter and receiver, connection orientation, cable routing, firmware compatibility, neutral/failsafe checks, RC mode selection, and the lifted-wheel test.

## Blade swapping

Will cover compatible blade types, safe restraint, exact tools, fastener direction, removed-part order, tightening requirement, clearance, balance, and a guarded low-speed test.
