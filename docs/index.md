# Twentynine Robotics Guides

Learn how to prepare your computer, upload a program, and work with your robot one step at a time.

Start with the guide for your robot. Instructions explain the controls and expected results in words, so you can follow them without pictures.

## Mini Hunter

[Mini Hunter guides](mini-hunter/)

Start here if you use a Mini Hunter with a FullVision STM32 V1.5 controller. The guide covers Windows software installation, the required libraries, checking your program, and the supported USB programming procedure.

[Downloads and installation links](mini-hunter/downloads.html)

Find the FullVision installer, Arduino IDE, STM32CubeProgrammer, and library downloads in one place.

[Mini Hunter photo checklist](mini-hunter/photo-checklist.html)

Use the reference numbers in the guide to take and add supporting photos gradually. The written instructions are complete enough to use while photos are still pending.
